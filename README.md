# Rust Learning Project

Welcome to the Rust Learning Project! This repository is designed to help you learn Rust through practical examples and structured modules.

## Project Structure

The project is organized into modules, each focusing on a specific Rust concept:

- `src/variables_and_mutability`: Learn about variable declarations, mutability, shadowing, and constants
- `src/data_types`: Explore scalar and compound data types in Rust
- `src/functions_and_control_flow`: Understand functions, if/else expressions, and loop constructs
- `src/ownership_and_borrowing`: Master Rust's ownership system, borrowing, and references
- `src/structs_and_methods`: Learn about struct definitions, instances, and method implementations
- `src/enums_and_pattern_matching`: Discover enum definitions, the match expression, and pattern matching
- `src/error_handling`: Study Rust's approach to error handling using Result and Option
- `src/collections`: Work with vectors, strings, and hash maps

## How to Use This Project

1. Run the project to see all examples:
   ```bash
   cargo run
   ```

2. Explore individual modules by looking at the code in each directory

3. Each module contains:
   - A `README.md` file with detailed explanations and exercises
   - An `examples.rs` file with working code examples
   - A `mod.rs` file that makes the module accessible

## Learning Path

We recommend following this learning path:

1. Start with **Variables and Mutability** to understand Rust's approach to variable declarations
2. Move on to **Data Types** to learn about Rust's type system
3. Study **Functions and Control Flow** to understand how to structure your code
4. Dive into **Ownership and Borrowing**, which is one of Rust's most unique features
5. Learn about **Structs and Methods** to create custom data types
6. Explore **Enums and Pattern Matching** for powerful data modeling
7. Study **Error Handling** to write robust code
8. Finally, work with **Collections** to handle groups of data

## Getting Started

1. Make sure you have Rust installed. If not, follow the instructions at [https://www.rust-lang.org/tools/install](https://www.rust-lang.org/tools/install)

2. Clone this repository

3. Run the project:
   ```bash
   cargo run
   ```

4. Explore the code and modify examples to experiment
